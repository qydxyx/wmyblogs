问之前

数据从哪来？

运行时读取 GitHub 仓库 taizihuang/wmyblog 的 search JSON（也可走 jsDelivr）。正文、后注、评论、访谈都在里面。原站 UDN 对脚本不开放，不作为主源。

观点改过怎么办？

后注和较新的回复权重大。答案会写明日期。旧正文仍可被检索，当作历史记录。

模型配在哪？

Embedding 和聊天必须写在服务器环境变量里。Rerank 可空。词面检索仍在浏览器完成，对照和作答走 /api/refine 与 /api/chat。

密钥会进浏览器吗？

不会。密钥只在服务器环境变量。页面不收、不存、不转发密钥。

怎么部署？

静态文件可放 Cloudflare Pages 或 Vercel；Functions 提供 /api/config、/api/refine、/api/chat。Docker 镜像用 Node 同时提供页面和接口。部署后再写入 EMBED_*、CHAT_*，可选 RERANK_*。

和镜像站搜索有何不同？

镜像站是关键词扫描。这里把问答成对检索，再用服务器上的 embedding（及可选 rerank）对照，并由聊天模型带引用作答。
